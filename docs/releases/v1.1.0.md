## 새로 생긴 것

- **자동 업데이트**: 프로그램을 켜면 새 버전을 확인해 위쪽에 알려 줍니다. [지금 업데이트] → [다시 시작]으로 바뀌고, 설정과 키는 그대로 남습니다.
- **내려받기 페이지**: https://kkchori511.github.io/ncloud-pdf-ocr/ (다른 사람에게는 이 주소를 알려 주세요)
- **묶기 확인**: OCR 뒤 페이지 그림을 학생별로 보여 줍니다. [새 학생]으로 학생을 나누고 [빼기]로 백지·표지를 뺍니다. 학생마다 장수가 달라도 됩니다.
- **원본 보기**: 스캔 그림과 OCR 글자를 나란히 봅니다. 2단계 학생 카드에도 [원본 보기]가 있습니다.
- **못 읽은 쪽만 다시 읽기**: OCR을 중지하거나 일부 쪽이 실패해도 읽은 쪽은 남고, 나머지만 다시 읽습니다.
- **2단 나누기·기울기 보정**: 한 쪽에 글이 두 단이면 왼쪽 단 → 오른쪽 단 순서로 읽습니다. 조금 기운 스캔은 바로잡고, 많이 기울면 다시 스캔하라고 알려 줍니다.

## 바뀐 것

- 학번·이름은 프로그램이 머리글에서 먼저 찾고, 그 줄을 지운 본문만 AI에 보냅니다. 못 찾은 학생만 머리글을 함께 보내 AI가 찾습니다(카드에 'AI가 찾음' 표시).
- 1단계가 OCR → 묶기 확인 → 정제 순서가 되었습니다. 예전처럼 한 번에 하려면 [묶기 확인 없이 OCR 뒤 바로 정제]를 체크하세요.
- 다른 사람에게 줄 때는 exe 파일만 전달하라는 안내를 넣었습니다(키는 exe 옆 설정 파일에 평문으로 저장됩니다).
