# 악필교정기 디자인 시안 요청서

Windows용 데스크톱 앱(창 크기 1280x900, 한국어 UI). 교사가 학생 과제 스캔 PDF를 OCR하고 AI로 정제·변환해 xlsx로 저장한다.
현재 화면 참고: `docs/design/current_stage2.png` (지금 디자인, 구분이 약하고 글씨가 작다는 피드백).

## 공통 조건

- 본문 글씨 15~16px, 제목은 더 크게. 글씨는 진하고 선명하게.
- 버튼 위계가 한눈에 구분돼야 함: 주 버튼(채움), 보조 버튼(테두리), 위험 버튼(붉은색).
- 탭, 영역, 카드의 경계가 분명해야 함(테두리·배경·간격).
- 구분자는 가운데 점(·) 대신 하이픈(-).
- 전문적인 업무용 앱 느낌.

## 그릴 화면: 작업 공간 (위에서 아래로)

1. 상단 바
   - 왼쪽: 메뉴 3개 `사용 안내` `설정` `작업 공간`(현재 선택됨)
   - 가운데: 박스 `이번 실행 0.0063 크레딧 사용 / 잔액 4.87 크레딧`
   - 오른쪽: 박스 안에 작은 캐릭터 얼굴 아이콘(`assets/face_ref.png`, 32px) + `악필교정기 v1.0.0`, 그 아래 회색 작은 글씨 `Made by 김한량 디지털 공방`
2. 1단계 카드(접힌 상태): 한 줄 `1단계 - OCR과 정제` `완료 - 2학년3반_과제.pdf, 12명` `[펼치기]`
3. 2단계 카드 `2단계 - 변환`
   - 테두리로 묶인 지침 영역:
     - 탭 5개 `요약` `세특` `프롬프트 3` `프롬프트 4` `프롬프트 5`
     - 한 줄: `탭 이름 [세특]` 옆 안내 `선택한 탭의 지침으로 변환합니다.` 오른쪽 `목표 분량 [1500] 바이트`
     - 좌우 반반: `변환 지침(프롬프트)` 큰 입력칸 | `예시 (선택) 1,482바이트` 큰 입력칸 (한글 약 600자 예시가 꽉 찬 모습)
   - 메뉴창: 이름표 붙은 4개 묶음 박스
     - `정렬`: 스캔순(선택) 학번순 이름순
     - `변환 대상`: 전체 선택, 전체 해제, [체크한 학생 변환](주 버튼)
     - `결과 선택`: 1안 전체 선택, 2안 전체 선택, 선택 해제
     - `저장`: 변환 없이 저장, [xlsx 저장](주 버튼, 맨 오른쪽)
   - 학생 카드 2명 (카드끼리 확실히 구분)
     - 머리줄: 체크박스, `2번째 학생 (p.3-4)`, `학번 [10101]`, `이름 [ ]`(비어 있어 노란 강조), `1안 선택됨` 표시, 오른쪽 `[2번째 학생 다시 변환]`
     - 본문: 3칸이 간격을 두고 각각 테두리 박스 `원본 111바이트` | `1안 95 / 150바이트`(범위 벗어나 빨강) | `2안 148 / 150바이트`
     - 1안·2안 아래에 `[1안 선택]` `[2안 선택]` 버튼, 선택된 안은 강조

## 시안 3개

- 시안 A: 토스·네이버 웍스 참고. 밝고 둥근 카드, 초록(#03c75a) 강조색, 친근함.
- 시안 B: Linear·Notion 참고. 무채색 위주, 얇고 선명한 구분선, 정돈된 업무용.
- 시안 C: Windows 11·Microsoft 365(Fluent) 참고. Windows 기본 앱 느낌, 파란 강조색.

각 시안은 1장(1280x900 비율 화면 목업), 한국어 글자가 깨지지 않게.
