# 악필교정기 1.0.0 명세

학생 과제 스캔 PDF를 CLOVA OCR(General)로 읽고, OpenRouter AI로 정제·변환해 xlsx로 내보내는 Windows용 단일 exe 프로그램.

## 화면 구성

- 상단 바: 왼쪽 메뉴(사용 안내, 설정, 작업 공간), 가운데 크레딧 박스(`이번 실행 N 크레딧 사용 / 잔액 N 크레딧`), 오른쪽 브랜드 박스(캐릭터 얼굴, `악필교정기 v1.0.0`, 회색 `Made by 김한량 디지털 공방`). 브랜드 박스를 누르면 "자유롭게 배포 가능하지만 반드시 키 초기화하고 배포하세요." 안내.
- 시작 화면: 키가 비어 있으면 설정(가입 안내 펼침), 있으면 작업 공간.
- 디자인: 시안 A 구조, 블루그레이 배경, 파란 버튼, 흰 입력칸. 구분자는 하이픈(-).

## 기술

- Python 3.12, pywebview(화면은 HTML/JS), PyInstaller `--onefile`로 exe 한 개.
- Windows exe는 GitHub Actions Windows 러너에서 빌드한다.
- CLOVA·OpenRouter 호출은 Python에서 한다(브라우저 CORS 불필요).
- PDF 분할: pypdf. xlsx: openpyxl. HTTP: requests.

## 설정

- exe 옆 `악필교정기_설정.json`에 평문 저장(개발 실행 시 프로젝트 루트).
- 키: CLOVA Invoke URL, CLOVA Secret Key, OpenRouter API 키.
- 일반 설정: 정제 모델, 변환 모델, 정제 방식, 정제 프롬프트(A/B), 변환 프롬프트 5개(이름+내용), 목표 분량, OCR 언어.
- 연결 정보 순서: 가입·키 발급 안내(접힘, 탭 3개: CLOVA 가입, Secret Key / URL 발급, OpenRouter 키 발급) → OCR 언어 → CLOVA Secret Key → CLOVA Invoke URL → OpenRouter API 키 → 안내문과 [키 초기화].
- [키 초기화]: 확인 후 키 3개만 지운다.
- 안내문: 키는 프로그램 폴더 설정 파일에 저장됨, 공용 PC에서는 사용 후 초기화, 본인이 발급받은 키만 사용하고 타인의 키를 무단 사용하지 말 것.
- CORS 안내는 넣지 않는다. 사용 안내 메뉴에는 자세한 사용 순서만 둔다.
- 정제 프롬프트 A, B는 좌우로 나란히.

## 모델 선택

- 정제 모델, 변환 모델을 따로 지정한다.
- 각 칸에 OpenRouter 모델 페이지 링크(https://openrouter.ai/models, 기본 브라우저로 열기)와 [붙여넣기] 버튼.
- 모델 칸은 왼쪽 절반(입력, 모델 페이지, 붙여넣기), 오른쪽 절반에 굵은 단가.
- 모델 ID가 정해지면 OpenRouter `/api/v1/models`에서 단가(입력/출력, 1M 토큰당 크레딧)를 표시한다.
- 요금: 이번 실행 요금(응답 usage.cost 합)과 잔액(`/api/v1/credits`)을 크레딧 단위로 표시.

## 1단계: OCR + 정제 (자동)

1. PDF 선택, 학생 1명당 페이지 수 입력(기본 1). 전체 페이지가 나누어떨어지지 않으면 경고(진행은 가능, 마지막 학생은 남은 페이지).
2. CLOVA OCR을 10페이지씩 나눠 순차 호출(호출 간 1.1초), 페이지 번호를 유지해 합친다.
3. 페이지 수대로 학생을 묶는다.
4. 학생마다 정제 모델로 정제: 방식 A(최소 교정: 오인식·맞춤법·띄어쓰기만) 또는 B(문장 완성: 끊긴 문장 완성, 내용 추가 금지). 응답은 JSON `{student_id, name, text}`.
5. 끝나면 바로 2단계로 간다. 1단계 xlsx 자동 저장은 없다. 실패나 중지가 없으면 1단계 카드를 자동으로 접는다.

진행 창: 실행 중 단계별 진행 막대, 개수, 경과 시간, [중지]. 중지하면 이미 보낸 요청만 마치고 나머지는 건너뛴다(OCR 중이면 즉시 종료).

## 2단계: 변환

- 학생 목록: 학번·이름·원본 수정 가능. 못 찾은 학번/이름 칸은 노란색.
- 정렬: 스캔순 / 학번순 / 이름순.
- 지침 영역(테두리로 묶음): 탭 5개, 탭 이름 옆 "선택한 탭의 지침으로 변환합니다.", 목표 분량(바이트), 좌우로 `변환 지침(프롬프트)`와 `예시`. 칸 높이는 1단계를 접었을 때 화면 아래까지. 탭마다 지침과 예시를 저장하고, 예시가 있으면 자동으로 함께 보낸다.
- 바이트 계산: 한글(완성형·자모) 3바이트, 그 밖(영어·숫자·기호·공백·줄바꿈) 1바이트.
- 결과마다 `실제 / 목표 바이트` 표시, ±10% 벗어나면 색 표시. 자동 재시도 없음.
- 실행: 체크한 학생만 변환. 전체 선택/전체 해제, 학생별 [다시 실행].
- 결과 1안·2안(학생별): 1회차→1안, 2회차→2안, 3회차부터 2안→1안 이동, 기존 1안 삭제, 새 결과→2안. 1안이 삭제될 학생이 있으면 실행 전에 "N명의 1안 결과가 삭제됩니다" 경고 한 번.
- 학생 카드: 머리줄(체크, N번째 학생, 학번, 이름, 선택 표시, [N번째 학생 다시 변환]), 원본·1안·2안을 테두리 박스로 분리. 1안·2안은 긴 쪽 내용이 다 보이게 높이를 맞추고 원본은 스크롤.
- 메뉴창: 이름표 붙은 묶음 4개(정렬, 변환 대상, 결과 선택, 저장). 저장 묶음은 [변환 없이 저장] [xlsx 저장] 순.
- 결과 선택: 학생별 1안/2안 선택, [1안 전체 선택] [2안 전체 선택] [선택 해제].

## 저장

- [xlsx 저장]: 한 파일, 저장 대화상자로 파일명을 묻는다. A 학번, B 이름, C 원본, D 변환(선택한 안). 선택 안 한 학생은 D 비움, 저장 전 "선택 안 된 학생 N명" 알림. 행 순서는 화면 정렬 순서.
- [변환 없이 저장]: A~C만.
