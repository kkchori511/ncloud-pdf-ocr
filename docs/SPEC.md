# 악필교정기 1.2.1 명세

학생 과제 스캔 PDF를 CLOVA OCR(General)로 읽고, OpenRouter AI로 정제·변환해 xlsx로 내보내는 Windows용 단일 exe 프로그램.

## 화면 구성

- 앱 아이콘(exe): `assets/icon.png`(1024px 원본) → `assets/icon.ico`(16·24·32·48·64·128·256px). 손글씨가 스캔선을 지나 엑셀 표로 정리되는 그림(C안). 앱 안의 얼굴 그림(`app/web/face.png`)은 따로 그대로 쓴다.
- 시작 화면: 실행하면 테두리 없는 420×420 창에 큰 앱 아이콘, 페이퍼로지 ExtraBold "악필교정기", 그 아래 버전. 로딩바 없음. 본 창은 숨겨 두었다가 화면 준비 신호(`app_ready`)가 오면 시작 화면을 닫고 띄운다. 시작 화면이 그려진 때부터 최소 1.5초, 신호가 안 오면 20초 뒤 본 창. 글꼴은 이 글자들만 남긴 페이퍼로지 서브셋(OFL, `app/web/fonts/`), 글꼴과 아이콘은 data URL로 넣는다.

- 상단 바: 왼쪽 메뉴(사용 안내, 설정, 작업 공간), 가운데 크레딧 박스(`이번 실행 N 크레딧 사용 / 잔액 N 크레딧`), 오른쪽 브랜드 박스(캐릭터 얼굴, `악필교정기 v1.0.0`, 회색 `Made by 김한량 디지털 공방`). 브랜드 박스를 누르면 앱 정보 창: 큰 얼굴, `악필교정기 v버전`, 소개 문구, `Made by 김한량 디지털 공방`, 업데이트 확인 결과, 배포 안내(내려받기 페이지 주소, exe만 전달, 키는 설정 json에 평문 저장, 키 초기화).
- 시작 화면: 키가 비어 있으면 설정(가입 안내 펼침), 있으면 작업 공간.
- 디자인: 시안 A 구조, 블루그레이 배경, 파란 버튼, 흰 입력칸. 구분자는 하이픈(-).

## 배포와 업데이트

- `v*` 태그 push → GitHub Actions(Windows): 시험(`tests/run_all.py`), 태그와 `VERSION` 일치 확인, exe 빌드, exe 자체 시험(`--selftest`), 업데이트 교체 시험(`--selftest-swap`) → Release에 `Akpil.exe` 첨부 → `gh-pages`에 내려받기 페이지(`site/index.html`)와 `Akpil-버전.exe`(최신 1개) 게시.
- 내려받기 페이지: https://kkchori511.github.io/ncloud-pdf-ocr/
- 앱을 켜면 최신 Release를 확인해 새 버전이면 위쪽에 알림 줄([바뀐 내용] [지금 업데이트] [나중에]).
- [지금 업데이트]: Release의 `Akpil.exe`를 받는다(막히면 Pages의 `Akpil-버전.exe`, 끊기면 이어 받기). GitHub가 붙인 SHA-256으로 확인한 뒤 실행 중인 exe를 `.old`로 이름 바꾸고 새 exe를 그 자리에 둔다. 버튼이 [다시 시작]으로 바뀌고, 누르면 새 exe를 켜고 창을 닫는다. 새 버전은 켜질 때 `.old`·`.new`를 지운다.
- 외부 스크립트(PowerShell·배치)는 쓰지 않는다. 설정 json은 그대로 남는다. 기록: exe 옆 `악필교정기_업데이트_기록.txt`.
- Windows exe가 아니거나 검증값이 없으면 [내려받기 페이지]를 연다.

## 기술

- Python 3.12, pywebview(화면은 HTML/JS), PyInstaller `--onefile`로 exe 한 개.
- Windows exe는 GitHub Actions Windows 러너에서 빌드한다.
- CLOVA·OpenRouter 호출은 Python에서 한다(브라우저 CORS 불필요).
- PDF 분할: pypdf. 페이지 그림: pypdfium2. xlsx: openpyxl. HTTP: requests.

## 설정

- exe 옆 `악필교정기_설정.json`에 평문 저장(개발 실행 시 프로젝트 루트).
- 키: CLOVA Invoke URL, CLOVA Secret Key, OpenRouter API 키.
- 일반 설정: 정제 모델, 변환 모델, 정제 방식, 정제 프롬프트(A/B), 변환 프롬프트 5개(이름+내용), 목표 분량, OCR 언어, 2단 나누기, 읽을 단, 묶기 확인 건너뛰기, 읽는 방식, 위쪽 가림 비율.
- Qwen으로 스캔 읽기(설정 화면): 그림 읽기 모델, OCR 보정 모델, 가림 0% 전송 동의.
- 안내문에 '다른 사람에게는 exe만 전달하거나 내려받기 페이지 주소를 알려 주세요'를 넣는다.
- 연결 정보 순서: 가입·키 발급 안내(접힘, 탭 3개: CLOVA 가입, Secret Key / URL 발급, OpenRouter 키 발급) → OCR 언어 → CLOVA Secret Key → CLOVA Invoke URL → OpenRouter API 키 → 안내문과 [키 초기화].
- [키 초기화]: 확인 후 키 3개만 지운다.
- 안내문: 키는 프로그램 폴더 설정 파일에 저장됨, 공용 PC에서는 사용 후 초기화, 본인이 발급받은 키만 사용하고 타인의 키를 무단 사용하지 말 것.
- CORS 안내는 넣지 않는다. 사용 안내 메뉴에는 자세한 사용 순서만 둔다.
- 정제 프롬프트 A, B는 좌우로 나란히.

## 모델 선택

- 정제 모델, 변환 모델을 따로 지정한다.
- 각 칸에 OpenRouter 모델 페이지 링크(https://openrouter.ai/models, 기본 브라우저로 열기)와 [붙여넣기] 버튼.
- 모델 칸은 왼쪽 절반(입력, 모델 페이지, 붙여넣기), 오른쪽 절반에 굵은 단가.
- 모델 ID가 정해지면 OpenRouter `/api/v1/models`에서 단가(입력/출력, 1M 토큰당 크레딧)를 표시한다.
- 요금: 이번 실행 요금(응답 usage.cost 합)과 잔액(`/api/v1/credits`)을 크레딧 단위로 표시.

## 1단계: OCR → 묶기 확인 → 정제

스캔 기능은 생기부착즙기(sgb-juicer)의 `scan.py`·`ocr.py`·`ocr_layout.py`·`ocr_vision.py`·`ocr_compare.py`를 가져와 쓴다. 한 PDF의 상태(CLOVA·Qwen 결과, 단 설정, 검토)는 `session.py`가 메모리에 둔다(앱을 끄면 사라짐).

0. 읽는 방식: CLOVA만(기본) / Qwen만 / 하이브리드.
   - Qwen: 페이지 그림을 OpenRouter의 Qwen3 VL(235B 기본, 8B 선택)에 쪽마다 한 번 보낸다(3개씩 동시). 학습 차단·보존 안 함(`data_collection: deny`, `zdr: true`)을 항상 켜고, 받는 곳이 없으면 보내지 않는다. 키·잔액·제공업체 오류면 남은 쪽은 보내지 않는다. 비용은 상단 크레딧에 더한다.
   - 위쪽 가리기: Qwen에 보낼 그림의 위쪽 N%(0~40, 기본 12)를 흰색으로 덮는다(이 PC 안). 첫 쪽 미리보기. 0%는 설정의 동의가 있어야 한다. 이미 Qwen에 보낸 쪽이 있으면 처음 비율·모델을 그대로 쓴다.
   - 하이브리드: 원본 보기에 '다르게 읽은 곳' 목록(원본 그 줄 확대 그림, 앞뒤 문맥, [CLOVA]·[Qwen]·[고치기]). [모두 CLOVA]·[모두 Qwen]·[고른 것 지우기]. 고르지 않은 곳은 CLOVA 글. 가린 위쪽의 CLOVA 줄은 비교하지 않고 CLOVA 글 그대로. 두 결과가 크게 다르면(비슷한 정도 75% 미만) 쪽 전체로 고른다. CLOVA가 그림 속 글자로 읽은 줄은 Qwen 그림 설명([그림: …])이 대신한다(끌 수 있음).
   - [AI 제안]: 그림 없이 다른 곳의 두 후보와 앞뒤 문맥만 OCR 보정 모델(비우면 정제 모델)에 보낸다. 학번·이름(규칙으로 읽은 값, 라벨 뒤 값)은 ○로 지운다. 제안은 표시만 하고 [제안 모두 받기]를 눌러야 고른 것이 된다.
   - 모든 쪽은 [직접 고치기]로 정제에 쓸 글을 통째로 고칠 수 있다.

1. PDF 선택, 학생 1명당 페이지 수 입력(기본 1). 전체 페이지가 나누어떨어지지 않으면 경고.
2. 읽을 단: 둘 다(기본) / 왼쪽만 / 오른쪽만. 한쪽만이면 2단으로 나눠 그 단의 줄만 남기고, 빼는 단 맨 위의 학번·이름 줄은 남긴다. Qwen에는 CLOVA가 찾은 경계(없으면 가운데)로 자른 그림만 보낸다(하이브리드는 CLOVA를 먼저 읽고 Qwen). 읽은 뒤 바꾸면 CLOVA는 다시 배치하고, 그 쪽 Qwen 결과는 지워 [못 읽은 쪽 다시 읽기]로 다시 보낸다. 원본 보기에 단 경계(빨간 점선)와 빼는 단(회색), Qwen에 가린 곳을 그린다.
   2단 나누기: 자동(기본) / 나누지 않음 / 항상 2단. CLOVA 낱말 좌표로 기울기(10° 이하)를 바로잡고, 단 사이 여백을 찾아 왼쪽 단 → 오른쪽 단 순서로 줄을 만든다. 많이 기울면 '다시 스캔 권장' 표시. 원본 보기에서 쪽마다 따로 바꿀 수 있다(2단 나누기·읽을 단 모두).
3. CLOVA OCR을 10페이지씩 나눠 순차 호출(호출 간 1.1초). 구간마다 받은 결과는 바로 보관해, 중지하거나 중간에 실패해도 읽은 쪽은 남는다. [못 읽은 쪽 다시 읽기]는 안 읽었거나 실패한 쪽만 다시 보낸다.
4. 묶기 확인: 페이지 썸네일을 학생별로 보여 준다. [새 학생](그 쪽부터 다음 학생), [빼기](정제에서 제외), [학생당 페이지 수로 다시 묶기]. 썸네일을 누르면 원본 보기(큰 그림 + OCR 글자, 이전/다음 쪽, 쪽별 2단 나누기). 그림은 pypdfium2로 이 PC 안에서 그린다.
5. 학번·이름은 AI 없이 규칙으로 머리글(첫 8줄)에서 찾는다: `학번:`, `이름:`/`성명:`(다음 줄 이름 포함), `2학년 3반 1번`, 5자리 숫자. 묶기 확인에 학생마다 찾은 값을 보여 준다(못 찾으면 노란 표시).
6. [정제 시작]: 쪽마다 머리글의 학번·이름·라벨 줄을 지운 본문을 만든다.
   - 학번·이름을 모두 찾은 학생: 지운 본문만 보낸다. 응답 JSON `{text}`.
   - 하나라도 못 찾은 학생: 첫 쪽 머리글 8줄을 `<머리글>`로 함께 보내 AI가 찾는다. 응답 JSON `{student_id, name, text}`. 규칙으로 찾은 값이 있으면 그 값을 쓴다. 2단계 카드에 'AI가 찾음' 표시.
   - 정제 방식 A(최소 교정) / B(문장 완성)는 그대로.
7. [묶기 확인 없이 OCR 뒤 바로 정제]를 체크하면 OCR이 문제없이 끝났을 때 기본 묶기로 바로 정제한다.
8. 끝나면 2단계로 간다. 실패나 중지가 없으면 1단계 카드를 자동으로 접는다. 2단계 학생 카드의 [원본 보기]는 그 학생의 쪽만 보여 준다.

진행 창: OCR(PDF 분할, OCR 구간)과 정제(명)를 따로 띄운다. 경과 시간, [중지]. 중지하면 이미 보낸 요청만 마치고 나머지는 건너뛴다.

## 2단계: 변환

- 학생 목록: 학번·이름·원본 수정 가능. 못 찾은 학번/이름 칸은 노란색.
- 정렬: 스캔순 / 학번순 / 이름순.
- 지침 영역(테두리로 묶음): 탭 5개, 탭 이름 옆 "선택한 탭의 지침으로 변환합니다.", 목표 분량(바이트), 좌우로 `변환 지침(프롬프트)`와 `예시`. 칸 높이는 1단계를 접었을 때 화면 아래까지. 탭마다 지침과 예시를 저장하고, 예시가 있으면 자동으로 함께 보낸다.
- 바이트 계산: 한글(완성형·자모) 3바이트, 그 밖(영어·숫자·기호·공백·줄바꿈) 1바이트.
- 결과마다 `실제 / 목표 바이트` 표시, ±10% 벗어나면 색 표시. 자동 재시도 없음.
- 실행: 체크한 학생만 변환. 전체 선택/전체 해제, 학생별 [다시 실행].
- 결과 1안·2안(학생별): 1회차→1안, 2회차→2안, 3회차부터 2안→1안 이동, 기존 1안 삭제, 새 결과→2안. 1안이 삭제될 학생이 있으면 실행 전에 "N명의 1안 결과가 삭제됩니다" 경고 한 번.
- 학생 카드: 머리줄(체크, N번째 학생, 학번, 이름, 선택 표시, [N번째 학생 다시 변환]), 원본·1안·2안을 테두리 박스로 분리. 1안·2안은 긴 쪽 내용이 다 보이게 높이를 맞추고 원본은 스크롤.
- 메뉴창: 이름표 붙은 묶음 4개(정렬, 변환 대상, 결과 선택, 저장). 저장 묶음은 [변환 없이 저장] [xlsx 저장] 순.
- 결과 선택: 학생별 1안/2안 선택, [1안 전체 선택] [2안 전체 선택] [선택 해제].

## 저장

- [xlsx 저장]: 한 파일, 저장 대화상자로 파일명을 묻는다. A 학번, B 이름, C 원본, D 변환(선택한 안). 선택 안 한 학생은 D 비움, 저장 전 "선택 안 된 학생 N명" 알림. 행 순서는 화면 정렬 순서.
- [변환 없이 저장]: A~C만.
