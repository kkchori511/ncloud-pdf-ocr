이번 실행 - 크레딧 사용 / 잔액 - 크레딧

사용 순서

처음 한 번: 설정

  1. 상단 설정을 엽니다. 키가 없다면 연결 정보 맨 위의 가입 - 키 발급 안내를 펼쳐 차례대로 따라 합니다.
  2. OCR 언어를 고르고, 네이버 콘솔에서 복사한 CLOVA Secret Key와 CLOVA Invoke URL, OpenRouter API 키를 붙여넣습니다. 입력하면 자동 저장됩니다.
  3. AI 모델에서 [모델 페이지]를 눌러 OpenRouter 모델 목록을 열고, 쓸 모델의 ID(예: google/gemini-2.5-flash)를 복사한 뒤 [붙여넣기]를 누릅니다. 오른쪽에 100만 토큰당 단가가 나오면 올바른 모델입니다.
    • 정제 모델은 학생 수만큼 호출되니 저렴하고 빠른 모델을 권합니다.
    • 변환 모델은 글 품질이 중요하니 성능 좋은 모델을 권합니다.
  4. 필요하면 정제 프롬프트 A(최소 교정), B(문장 완성)의 규칙을 고칩니다.

1단계 - OCR과 정제

  1. 작업 공간에서 [PDF 선택]으로 스캔한 과제 PDF를 고릅니다. 페이지 수가 함께 표시됩니다.
  2. 학생 1명당 페이지 수를 넣습니다. 단면 스캔은 1, 양면 스캔은 2입니다. 전체 페이지가 나누어떨어지지 않으면 경고가 뜹니다.
  3. 정제 방식을 고릅니다.
    • 최소 교정: OCR 오인식, 맞춤법, 띄어쓰기만 고칩니다.
    • 문장 완성: 끊긴 문장까지 자연스럽게 완성합니다. 새 내용은 넣지 않습니다.
  4. 2단 나누기: 가로로 놓인 A3처럼 한 쪽에 글이 두 단이면, 자동으로 왼쪽 단을 다 읽은 뒤 오른쪽 단을 읽습니다. 섞여 나오면 [항상 2단으로], 한 단짜리인데 잘못 나뉘면 [나누지 않음]을 고르세요. 기울어진 스캔은 조금(10도 이하) 바로잡고, 너무 기울면 다시 스캔하라고 알려 줍니다.
  5. [1단계 시작]을 누르면 진행 창이 뜹니다. OCR은 10페이지씩 나눠 읽습니다. 경과 시간이 올라가고 있으면 정상 진행 중입니다. 잘못 시작했다면 [중지]를 누르세요. 중지해도 이미 읽은 쪽은 남고, [못 읽은 쪽 다시 읽기]로 나머지만 읽습니다.
  6. 묶기 확인: 페이지 그림이 학생별로 나옵니다. 학생마다 장수가 다르면 그 학생 첫 페이지의 [새 학생]을 누르고, 백지나 표지는 [빼기]를 누릅니다. 페이지를 누르면 원본과 OCR 글자를 나란히 봅니다.
  7. 학번과 이름은 머리글(학번:, 이름:, 2학년 3반 1번 같은 줄)에서 프로그램이 찾고, 그 줄을 지운 본문만 AI에 보냅니다. 못 찾은 학생만 머리글을 함께 보내 AI가 찾습니다.
  8. [정제 시작]을 누르면 학생마다 정제합니다. 묶기를 확인할 필요가 없으면 묶기 확인 없이 OCR 뒤 바로 정제를 체크해 두세요.
  9. 문제없이 끝나면 1단계는 자동으로 접히고 2단계 학생 목록이 나옵니다. 학생 카드의 [원본 보기]로 스캔 그림과 대조할 수 있습니다.

2단계 - 변환

  1. 학생 카드에서 학번과 이름을 확인합니다. 노란 칸은 찾지 못한 곳이니 직접 입력하세요. 원본도 고칠 수 있습니다.
  2. [학번순], [이름순]으로 정렬하면 빠진 학생이나 잘못 읽은 학번을 찾기 쉽습니다.
  3. 지침 탭을 고르고 변환 지침(프롬프트)을 씁니다. 원하는 결과 모양의 글을 예시 칸에 넣으면 AI가 문체와 형식을 참고합니다. 탭 5개에 각각 다른 지침과 예시를 저장해 둘 수 있습니다.
  4. 목표 분량을 바이트로 넣습니다. 한글 1자는 3바이트, 영어, 숫자, 기호, 공백은 1바이트입니다. 결과 바이트 수가 목표에서 10% 넘게 벗어나면 빨갛게 표시됩니다.
  5. 변환할 학생을 체크하고 [체크한 학생 변환]을 누릅니다. 결과는 1안에 들어갑니다.
  6. 다시 변환하면 2안에 들어갑니다. 그다음부터는 2안이 1안으로 옮겨지고 기존 1안은 지워지며, 새 결과가 2안에 들어갑니다. 지워지기 전에 경고가 뜹니다.
  7. 한 학생만 다시 돌리려면 카드의 [N번째 학생 다시 변환]을 누릅니다.

저장

  1. 학생마다 [1안 선택] 또는 [2안 선택]을 누릅니다. [1안 전체 선택], [2안 전체 선택]으로 한 번에 고를 수도 있습니다.
  2. [xlsx 저장]을 누르고 파일 이름을 정합니다. A~D열에 학번, 이름, 원본, 변환 내용이 화면 정렬 순서대로 저장됩니다. 안을 고르지 않은 학생은 변환 칸이 비어 있습니다.
  3. 변환 없이 원본만 필요하면 [변환 없이 저장]을 누릅니다. A~C열만 저장됩니다.

다른 사람에게 줄 때

  • 다른 사람에게는 내려받기 페이지 주소(kkchori511.github.io/ncloud-pdf-ocr)를 알려 주세요.
  • 파일을 직접 줄 때는 exe 파일만 전달하세요. 키는 exe 옆 악필교정기_설정.json에 평문으로 저장되어, 폴더째 주면 내 키도 함께 넘어갑니다. 공용 PC라면 설정 > 연결 정보의 [키 초기화]로 키를 지우세요.

업데이트

  • 프로그램을 켜면 새 버전이 있는지 확인하고, 있으면 위쪽에 알림이 뜹니다. [지금 업데이트]를 누르면 새 버전을 받아 바꿔 두고, [다시 시작]을 누르면 새 버전으로 켜집니다. 설정과 키는 그대로 남습니다.
  • 학교 인터넷이 GitHub를 막아 받지 못하면 내려받기 페이지에서 직접 받아 exe를 바꿔 주세요.

연결 정보

처음 사용하시나요? 가입 - 키 발급 안내 펼치기
  1. openrouter.ai에 가입하고 로그인합니다.
  2. Credits 메뉴에서 크레딧을 충전합니다. (1크레딧 = 1달러)
  3. Keys 메뉴에서 Create Key를 눌러 키를 만들고, 아래 OpenRouter API 키 칸에 붙여넣습니다.
  4. 키는 만들 때 한 번만 보이니 안전한 곳에 따로 보관하세요.
키는 이 프로그램 폴더의 설정 파일()에 평문으로 저장됩니다. 공용 PC에서는 사용 후 반드시 [키 초기화]를 눌러 주세요.
다른 사람에게 줄 때는 exe 파일만 전달하거나 내려받기 페이지 주소(kkchori511.github.io/ncloud-pdf-ocr)를 알려 주세요.
API 키는 본인이 발급받은 키만 사용해야 하며, 타인의 키를 무단으로 사용하는 것은 금지됩니다.
