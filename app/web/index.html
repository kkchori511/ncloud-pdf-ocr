처음 사용하기

  1. openrouter.ai에 가입하고 로그인합니다.
  2. Credits 메뉴에서 크레딧을 충전합니다. (1크레딧 = 1달러)
  3. Keys 메뉴에서 Create Key를 눌러 키를 만들고, 이 프로그램 설정의 OpenRouter API 키 칸에 붙여넣습니다.
  4. 키는 만들 때 한 번만 보이니 안전한 곳에 따로 보관하세요.
  1. 설정에서 키 3개와 정제 모델, 변환 모델을 입력합니다.
  2. 작업 › 1단계에서 PDF를 고르고 학생 1명당 페이지 수(단면 1, 양면 2)와 정제 방식을 정한 뒤 시작합니다.
  3. OCR과 정제가 끝나면 2단계에 학생 목록이 나옵니다. 노란 칸은 학번이나 이름을 찾지 못한 곳이니 직접 고쳐 주세요.
  4. 변환 지침 탭을 고르고 목표 분량을 넣은 뒤, 체크한 학생을 변환합니다. 다시 돌리면 두 번째 열에 결과가 나옵니다.
  5. 학생마다 마음에 드는 열을 고르고 xlsx 저장을 누릅니다. 변환이 필요 없으면 변환 없이 저장을 누릅니다.
