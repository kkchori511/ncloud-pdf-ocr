악필교정기 v__VERSION__

손글씨 과제 스캔을 OCR(CLOVA·Qwen)로 읽고, AI로 다듬어 엑셀(xlsx)로 정리하는 Windows 프로그램입니다.

Made by 김한량 디지털 공방
Windows용 내려받기 (v__VERSION__)
받은 파일 이름을 악필교정기.exe로 두고 원하는 폴더에 넣어 실행하세요. · GitHub 릴리스에서 받기

처음 쓰는 방법

  1. 내려받은 exe를 원하는 폴더(예: 문서 폴더 안 '악필교정기')에 넣고 실행합니다. 설정 파일이 그 폴더에 생깁니다.
  2. Windows가 "PC 보호" 창을 띄우면 추가 정보 → 실행을 누릅니다.
  3. 프로그램의 설정에서 가입·키 발급 안내를 따라 본인의 CLOVA OCR 키와 OpenRouter 키를 넣습니다.
  4. 새 버전이 나오면 프로그램 위쪽에 알림이 뜹니다. [지금 업데이트]를 누르면 바뀝니다. 설정과 키는 그대로 남습니다.

나눠 줄 때

  • 이 페이지 주소를 알려 주세요.
  • 파일을 직접 줄 때는 exe 파일만 전달하세요. 키는 exe 옆 악필교정기_설정.json에 평문으로 저장되어, 폴더째 주면 내 키도 함께 넘어갑니다.
  • API 키는 본인이 발급받은 키만 사용해야 합니다.
